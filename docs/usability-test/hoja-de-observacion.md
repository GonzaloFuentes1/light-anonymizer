# Prueba de usabilidad del Anonimizador: hoja de observación

Una hoja por participante. **No escribas nombres, RUT, cargos ni unidades.** Usa solo el código del participante.

|---|---|---|---|---|---|
| P__ | | (iniciales) | (iniciales) | | Sí / No |

Experiencia del participante (marca una): publica documentos por transparencia **a menudo** / **a veces** / **nunca**.

## Cómo llenar cada tabla

- **Completada:** Sí (sin ayuda) · Parcial (ver el criterio en [tareas.md](tareas.md)) · Con ayuda · No.
- **Tiempo:** minutos y segundos, desde que termina de leer la tarjeta hasta que dice que terminó o se cumple el límite.
- **Errores:** cada acción que no lo acerca a la meta (un clic equivocado, abrir otro archivo, quitar otra censura). Anota cuántos y cuáles.
- **Citas:** frases textuales del participante, entre comillas. Quita cualquier dato que identifique a alguien.
- **Gravedad** de cada problema: 1 cosmético · 2 menor · 3 mayor · 4 crítico (un dato personal quedaría publicado, o se censuraría información pública sin que lo note).
- **Facilidad (1 a 7):** la respuesta del participante a "¿Qué tan fácil o difícil fue esta tarea?" (1 = muy difícil, 7 = muy fácil).
